# mi-portafolio

Sitio web personal de Elkin Basto, Ingeniero de Sistemas. Sitio estático en HTML, CSS y JavaScript.

## Estructura

```
mi-portafolio/
├── index.html      Página principal
├── contacto.html   Página de contacto
├── css/            Estilos
├── js/             Scripts
├── img/            Imágenes
├── README.md       Este archivo
└── .gitignore      Archivos que Git no debe versionar
```

## Probar en local

Abre la carpeta en VS Code y usa la extensión **Live Server** (clic derecho en `index.html` → *Open with Live Server*).

## Publicación

Publicado con GitHub Pages desde la rama `main`. Cada `git push` actualiza el sitio.
